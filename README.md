# Neo_resin Luxury Boutique

Create a luxury Persian e-commerce website for a handmade resin art brand called Neo_resin. Use a black and gold color palette with a modern premium style. Include a hero section, categories for resin trays, clocks, jewelry, accessories, custom orders, featured products, about the artist, Instagram gallery, FAQ, contact page, shopping cart, and checkout. The website must be RTL and fully responsive. The brand slogan is “Handcrafted Resin Art”. Design it similar to a premium luxury boutique.
